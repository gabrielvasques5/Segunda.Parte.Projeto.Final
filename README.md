# Copa do Brasil — Segunda Parte do Projeto Final

Este projeto consiste num site web com temática da **Copa do Brasil**, estruturado com páginas HTML, folhas de estilo CSS e scripts JavaScript para navegação, interação e autenticação/login.

## Sobre o site

O site reúne uma página principal (`index.html`) e uma página dedicada ao login (`login.html`), onde o utilizador encontra um formulário de acesso (`#form-login`) com campos de e-mail e senha dentro de um contentor centralizado (`login-container` e `login-box`). A interface combina estilos visuais próprios com scripts no lado do cliente para responder às ações do utilizador


- `index.html` — Página principal do site
- `login.html` — Página de login com o título e cabeçalho temáticos da Copa do Brasil e formulário de entrada
- `style.css` — Regras visuais gerais aplicadas ao site
- `login.css` — Estilização específica da página de login e do respetivo formulário
- `modal.css` — Estilos responsáveis pela apresentação de modais na interface
- `script.js` — Comportamentos e interações gerais do site
- `login.js` — Lógica associada ao formulário e ao processo de login
- `img/` — Pasta onde ficam armazenadas as imagens utilizadas nas páginas e estilos
